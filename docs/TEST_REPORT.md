# 테스트 결과

검증일: 2026-10-19 (Asia/Seoul)

## 실행 환경
- 서비스: Python 내장 HTTP 서버, `http://127.0.0.1:8765`
- Python: Codex 번들 Python 실행 파일 사용. 시스템 `python` 명령은 Windows 실행 별칭으로 정상 동작하지 않아 번들 런타임으로 대체했다.
- 테스트: Node.js 24.12.0, Playwright, 설치된 Microsoft Edge의 별도 헤드리스 테스트 컨텍스트
- DB: Firebase CLI 15.34.0 공식 Authentication 및 Realtime Database 에뮬레이터, Java 21
- 서비스 구현: HTML/CSS/순수 JavaScript. 테스트 패키지는 프로젝트 외부에 설치했다.

## 결과
핵심 로직 및 DB 통합 테스트 11개, 브라우저 검증 19개 모두 통과했다.

### 핵심 로직 및 DB 통합 (11/11)
1. 한국 자정 전후 날짜 분리
2. 아이디 정규화·검증·DB 경로 변환
3. 한글/영문 문제 수 최소 요건 및 중복 검사
4. 목록 소진 전 문제 재출제 방지 및 묶음 경계 연속 중복 방지
5. 오타의 정확도·속도·점수 반영
6. 일일 산술 평균·최고점수·재저장 중복 방지·사용자/날짜 혼합 거절
7. Firebase 미설정 시 조회/저장 성공으로 표시하지 않음
8. ETag 충돌 발생 시 재조회 후 병합
9. 에뮬레이터 규칙의 인증 없는 읽기/쓰기 차단
10. 인증되었어도 필수 필드가 없는 데이터 저장 차단
11. 두 클라이언트 동시 저장에서 양쪽 회차 보존 및 재전송 중복 방지

### 브라우저 검증 (19/19)
1. 최초 아이디 팝업, 잘못된 아이디 안내, 상단 아이디 표시
2. 시간 및 진행횟수 전체 옵션과 기본값
3. 새 아이디에서 '이전자료가 없습니다.' 표시
4. 정답 입력 후 Enter 대기, 빈 입력·한글 조합·반복 Enter 방지
5. 오타 포함 5회 완료, 정확도 반영, 작업종료 이전 DB 쓰기 없음
6. 작업종료 없는 새로고침에서 DB 쓰기 없이 당일 임시 기록 복원
7. 영문 단어 출제, 여러 회차 최신순 표시
8. Firebase 에뮬레이터에 실제 저장·조회, 단일 날짜 그래프, 반복 저장 중복 방지
9. 저장 오류 후 기록 보존·재시도 및 같은 날짜 3회 합산
10. 30초 제한 시간 종료 및 입력 중 글자 집계
11. 중도 취소한 연습은 완료 기록에서 제외
12. 한국 자정 전날 완료 기록 자동 정산과 오늘 화면 초기화
13. 날짜별 기록 내림차순과 최고점수 그래프
14. 390px 모바일 페이지의 가로 넘침 방지
15. localStorage가 없는 새 브라우저에서 같은 아이디의 과거 기록 조회
16. 한글/영문 × 단어/짧은 문장/긴문장 6종 모두 정상 완료
17. 창을 닫고 다음날 접속했을 때 전날 미승인 기록을 자동 저장하지 않음
18. 자정에 진행 중인 미완료 연습은 취소하고 DB 저장에서 제외
19. 테스트 중 브라우저 JavaScript 실행 오류 없음

## 검증 범위와 미완료 항목
- 브라우저의 날짜와 시간은 자동 테스트 시 제어하여 30초 종료 및 자정 상황을 재현했다. 실제 운영 서버나 PC 시계는 변경하지 않았다.
- 한글 조합 중 Enter는 브라우저 이벤트로 검증했다. 여러 OS/실제 IME 조합별 수동 검증은 별도다.
- 실제 Firebase 프로젝트 설정이 아직 지정되지 않아 운영 DB와의 인증·저장·조회는 검증하지 않았다.
- Git 저장소를 로컬에 준비했으나 대상 GitHub 저장소와 Vercel 프로젝트가 지정되지 않아 원격 업로드 및 배포 URL 검증은 하지 않았다.
- 사용자의 후속 설정이 도착하면 실제 클라우드 연결, 원격 업로드, Vercel 배포 및 배포 URL 검증을 이어서 수행해야 한다.
