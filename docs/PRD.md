# 톡톡 타자 게임 PRD

## 목적과 기술
한글·영문 타자 연습을 제공하고 날짜별 성장을 확인하는 정적 웹 프로그램이다. HTML, CSS, 순수 JavaScript ES 모듈만 사용하며 Python HTTP 서버에서 테스트한다. DB는 Firebase Realtime Database이고 최종 소스 보관과 웹 공개 대상은 GitHub 및 Vercel이다.

## 시작 및 사용자
- 최초 표시 화면은 아이디 입력 팝업이다. 아이디 입력 전에는 연습을 시작할 수 없다.
- 아이디는 1~32자의 한글·영문·숫자·밑줄·하이픈으로 입력하고 NFC 정규화 및 앞뒤 공백 제거를 적용한다. 대소문자는 구분한다.
- 입력한 아이디를 화면 상단에 표시하고 옆에 나의 연습 기록 버튼을 둔다.
- 아이디는 기록 구분용 별칭이다. 비밀번호 인증을 제공하지 않으므로 같은 아이디를 아는 사용자는 기록을 조회·추가할 수 있다. Firebase 익명 인증은 REST API 호출에 사용한다.

## 디자인
- 배경은 연한 회색과 민트 장식, 카드는 흰색, 본문과 주요 버튼은 네이비를 사용한다.
- 민트는 주요 강조, 녹색은 성공 안내, 붉은색은 오류 안내다.
- Noto Sans KR, Malgun Gothic, 시스템 sans-serif 순서로 글꼴을 사용한다.
- 본문 최대 너비 900px, 중앙 정렬이며 600px 이하에서 통계와 설정을 2열로 배치한다.
- 상단: 브랜드, 사용자 아이디, 기록 조회 버튼, 연습 소개, DB 연결 안내.
- 연습 카드: 시간/문제 수, 속도, 정확도, 오늘 최고점수, 진행 막대, 설정 4개, 상태, 제시 문제, 입력란, 피드백, 시작/취소 버튼.
- 결과 카드: 최종 점수, 속도, 정확도, 정답 글자 수, 다시 도전하기.
- 오늘 기록: 날짜, 회차 수, 평균·최고점수, 평균 속도·정확도, 최신순 회차별 표, 작업종료 버튼, 저장 상태.
- 과거 기록: 날짜 내림차순 표와 날짜별 최고점수 꺾은선 그래프. 그래프는 시간 흐름을 따라 오래된 날짜를 왼쪽에 둔다.
- 긴 기록 표와 그래프는 내부 가로 스크롤을 제공하고 모바일 페이지 자체는 옆으로 넘치지 않게 한다.
- 입력과 버튼 포커스를 표시하며 피드백과 저장 상태를 스크린리더에 알린다. 그래프와 동일한 수치를 표에서도 확인한다.

## 연습 설정과 문제 은행
| 설정 | 선택값 | 기본값 |
| --- | --- | --- |
| 언어 | 한글타자 / 영문타자 | 한글타자 |
| 문제 유형 | 짧은 문장 / 단어 / 긴문장 | 짧은 문장 |
| 진행 방식 | 시간 / 진행횟수 | 시간 |
| 시간 | 30/60/90/120/150/180/210/240/270/300초 | 60초 |
| 진행횟수 | 5/10/15/20/25/30/35/40/45/50회 | 10회 |

- 한글 문제: 실제 단어 557개, 짧은 문장 120개, 긴문장 48개.
- 영문 문제: 실제 단어 640개, 짧은 문장 120개, 긴문장 48개.
- 짧은 문장은 12개 도입 구절과 10개 끝 구절, 긴문장은 8개 도입 문장과 6개 마무리 문장을 연결하여 구성한다. 언어·유형별 중복 문장은 없다.
- 각 목록을 Fisher–Yates 방식으로 섞어 하나씩 출제한다. 목록을 다 쓰기 전 재출제를 하지 않고 다음 묶음 시작에서도 직전 문제와 연속 중복을 방지한다.
- 연습 중 설정 변경은 잠근다. 시작하면 입력란에 포커스를 둔다.

## 입력과 완료
- 정답을 모두 입력해도 자동으로 넘어가지 않고 Enter 안내를 표시한다.
- Enter로만 제출하며 오타가 있어도 다음 문제로 진행한다.
- 빈 입력, 공백만 있는 입력, 반복 Enter는 제출하지 않는다. 한글 조합 중 Enter는 조합 확정으로 취급하고 제출하지 않는다.
- 시간 모드는 실제 경과 시간으로 종료한다. 타이머 간격 지연 때문에 시간이 늘어나지 않게 한다.
- 횟수 모드는 Enter 제출이 설정한 횟수에 도달하면 종료한다. 오타 제출도 진행횟수로 인정한다.
- 정상 완료 시 UUID가 있는 회차 기록을 생성하여 오늘 기록에 추가한다. 취소한 연습은 기록하지 않는다.
- 오늘 기록은 가장 최근 회차를 맨 위에 표시하고 1회부터 번호를 매긴다. 같은 날 접속한 기록을 함께 표시한다.

## 점수와 평균
- 같은 위치의 같은 글자만 정답 글자로 집계한다.
- 입력 길이가 늘어난 만큼 누적 입력 글자 수를 늘리며 삭제 후 다시 입력한 글자도 입력량에 반영한다.
- 정확도 = 정답 글자 수 / 누적 입력 글자 수 × 100, 정수 반올림. 입력이 전혀 없으면 100%, 점수는 0이다.
- 속도 = 정답 글자 수 / 실제 연습 초 × 60, 정수 반올림. 최소 1초로 계산한다.
- 점수 = 정답 글자 수 × 정확도 비율, 정수 반올림.
- 시간 종료 때 입력 중이던 글자도 현재 정답/오타 집계에 포함한다.
- 일일 평균 점수·속도·정확도는 정상 완료 회차별 산술 평균으로 소수 둘째 자리까지 반올림한다. 최고점수는 회차별 점수의 최댓값이다.
- 언어·유형·시간·횟수가 서로 다른 연습도 당일 전체 집계에 포함한다. 각 회차에 설정을 함께 보관한다.

## 저장과 날짜 변경
- 날짜 기준은 항상 Asia/Seoul의 YYYY-MM-DD다.
- 당일 기록은 사용자와 UUID별로 브라우저 localStorage에 임시 보관하여 같은 날 재접속해도 표시한다.
- 제한 시간/진행횟수 완료 자체로 DB 쓰기를 하지 않는다.
- 작업종료 버튼은 연습이 끝난 상태에서 활성화된다. 클릭하면 그날 완료 기록의 저장을 승인하고 Firebase의 기존 날짜 기록과 합쳐 평균과 최고점수를 갱신한다.
- 창 닫기나 새로고침 이벤트에서는 DB 저장을 요청하지 않는다.
- 화면이 열린 상태에서 날짜가 바뀌면 전날 완료 기록을 자동 정산하고 새 날짜 화면으로 전환한다. 진행 중 미완료 연습은 취소한다.
- 닫힌 브라우저는 자정 작업을 실행할 수 없다. 다음날 새 접속 때 전날 미승인 기록을 소급 저장하지 않는다.
- 작업종료 또는 자정 처리로 승인한 기록이 저장에 실패하면 저장 대기로 보관하고 재접속 또는 작업종료 시 재시도한다.
- UUID 병합과 Firebase ETag 조건부 쓰기로 재시도 중복 및 여러 화면 동시 저장의 덮어쓰기를 방지한다.
- 서버에서 성공 응답을 받은 뒤에만 저장 완료를 표시한다. 미설정·오류를 저장 완료로 표시하지 않는다.

## DB 조회와 그래프
- 필수 저장 항목: 사용자아이디 `userId`, 연습 날짜 `practiceDate`, 최고점수 `highestScore`.
- 일일 평균, 시도 수, 연습 시간, 문제 수, 설정을 포함한 회차별 기록, 갱신 시각도 저장한다.
- 경로: `practice/{아이디 UTF-8 hex}/days/{YYYY-MM-DD}`.
- 나의 연습 기록 버튼은 매번 DB를 조회한다. 날짜 내림차순으로 표시한다.
- 정상 조회 결과가 비어 있으면 '이전자료가 없습니다.'를 표시한다. 연결 오류는 별도 오류로 표시한다.
- 표 아래 SVG 꺾은선 그래프에 날짜별 최고점수와 날짜를 표시한다. 1개 날짜만 있어도 점을 표시하고 0점 기록도 표시한다.
